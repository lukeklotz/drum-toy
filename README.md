For now you can get it running locally by following these steps:

## Local Development

### 1. Change Directory
```bash
cd <whereever-you-installed-this>/drum-toy
```
### 2. Install Deps
```bash
npm install
```

### 3. Start Server
```bash
npm run dev
```
